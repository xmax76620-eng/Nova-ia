Créer ta scène

Le studio produit une scène 3D temps réel avec Three.js et un modèle 3D animé lorsqu'il est disponible. Tu peux tourner autour de la scène avec le doigt. Ce n'est pas Sora : sans modèle vidéo IA externe, NOVA ne peut pas inventer photoréalistement n'importe quel sujet à partir d'une phrase. Le rendu dépend des modèles 3D chargés.

L'export vidéo dépend de Safari/iOS. Laisse cette page ouverte pendant l'enregistrement. Le format exporté sera WebM si ton navigateur le permet.

Réglages de NOVA AI

Par défaut, NOVA utilise les routes sécurisées de ton site Vercel. La clé API reste sur le serveur et n'est jamais demandée ici.

Exemple : https://ton-worker.workers.dev si ton Worker expose /chat et /models. Pour le backend Vercel, laisse ce champ vide.
